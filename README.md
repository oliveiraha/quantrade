# QuanTrade

QuanTrade is a trading platform I've been developing for market analysis, trade execution and risk management.

The desktop application uses Python, FastAPI and React, with MetaTrader 5 integration for market data and order management.

The project started with custom MQL5 indicators and Expert Advisors. Over time, I added tools for volatility analysis, market screening, multi-timeframe charts, position management and trading reports.

I'm also working on an Android application and experimenting with local language models for market analysis.

The main areas of development are:

- Trading terminal and MetaTrader 5 integration
- Market data processing and visualization
- Multi-timeframe volatility and price action analysis
- Custom indicators and automated trading systems
- Order execution and position management
- Risk management and account monitoring

QuanTrade is still under development. This repository contains project documentation, screenshots and development updates. The application source code and trading strategies are not publicly available.
